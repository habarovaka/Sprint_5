Тестирование охватывает ключевые сценарии: регистрацию, авторизацию, личный кабинет и навигацию по конструктору ингредиентов.
СТРУКТУРА:
tests/ — папка с тестами, разделенными по файлам (логин, логаут, регистрация, конструктор).
locators.py — описание всех элементов страниц (XPath) с комментариями.
conftest.py — настройки драйвера и фикстуры (создание браузера, генерация данных пользователя).
README.md — краткое описание проекта.
.gitignore — список файлов, которые не попадают в репозиторий (venv, кэш).

ТЕСТЫ:
Регистрация: test_registration.py
-успешное создание пользователя
-проверка ошибки при пароле меньше 6 символов.
Вход (проверка всех четырех точек входа): test_login.py
- вход по кнопке «Войти в аккаунт» на главной,
- вход через кнопку «Личный кабинет»,
- вход через кнопку в форме регистрации,
- вход через кнопку в форме восстановления пароля.
Личный кабинет: test_cabinet.py
- выход из аккаунта
- переход по клику на «Конструктор» 
- на логотип Stellar Burgers
Конструктор: test_constructor.py
- переключение между разделами «Булки», «Соусы» и «Начинки» (проверка активности вкладок)
